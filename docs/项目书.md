# 浮游动物一体化（Android）项目书（交接版）

版本：v0.3（2026-07-27 更新）
主应用：**浮游动物一体化**（`com.plankton.one102`）  
语音助手：**语音识别助手**（`com.voiceassistant`）  
代码仓库：`https://github.com/yuelangmanle/plankton.git`

---

## 1. 项目目标

建设一套以 Android 为核心的浮游动物数据处理系统，覆盖：

- 采样点与物种计数录入
- 密度/生物量/多样性指数自动计算
- 表1/表2 的多工作表 `.xlsx` 导出
- AI 辅助（问答、补齐、核对、图片识别）
- 独立语音助手 App 接入（语音转写与批量指令）

原则：

- 离线优先，本地可完成核心流程
- 结果可追溯、可复核
- 模板驱动导出，保证格式稳定

## 4. 仓库与交付策略

### 4.1 交付内容（上传 GitHub）

- 源码（`android/`、`app/`、`voice_assistant/`）
- 关键文档（`docs/`）
- 工具脚本（`tools/`）

### 4.2 本地保留、不上传内容

以下内容通过 `.gitignore` 忽略：

- 构建产物与缓存（`build/`、`.gradle/`、`.tmp/`、`.toolchain/` 等）
- 历史 APK 与安装包产物（`apk_history/`、`*.apk`、`*.aab` 等）
- 本地模型目录（`voice_assistant/.../models`、`.../sherpa`）
- 所有表格文件（`*.xlsx`、`*.xls`、`*.csv`、`*.tsv`、`*.xlsm`、`*.ods`）
- API 调试与历史备份（`api_backups/`）、签名材料和密码（`.secrets/`、`*.jks`、`*.keystore`）

说明：这些文件保留在本地磁盘，不影响日常开发，但不会进入远程仓库。

### 4.3 开源仓库治理基线（2026-07-27）

- 根目录 `README.md` 作为唯一入口，说明模块范围、最低系统版本、构建方式、隐私边界和最新 Release。
- 原创代码采用 Apache-2.0；引入代码和依赖仍遵守各自许可证，集中说明见 `THIRD_PARTY_NOTICES.md`。
- `CONTRIBUTING.md`、`SECURITY.md`、`CODE_OF_CONDUCT.md`、`SUPPORT.md`、`CODEOWNERS`、Issue/PR 模板约束贡献、漏洞报告和敏感数据处理。
- GitHub Actions 验证 Android 主 App 单元测试/Debug 构建与 Web lint/build；CodeQL、Dependabot 和依赖审查负责持续发现代码和依赖风险。CI 不读取或生成正式签名私钥。
- `main` 只接受通过 CI 的 Squash merge；合并后自动删除分支。需要修改数据格式、导出、API、备份或权限时，PR 必须写明兼容性与人工真机验收步骤。

### 4.4 发布与维护边界

- GitHub Release 只上传使用既有正式证书签名的主 App APK，并附版本说明和 SHA-256；Debug 包和历史安装包只留本地归档。
- 每次应用行为变化均按 `docs/release-checklist.md` 完成版本、文档、加密资源、测试、签名与发布核对；仅仓库治理变更不递增 App 版本。
- 任何人接手维护前，应离线、安全地交接 `.secrets/release-signing/`，而非把私钥提交到 GitHub。

- `android/app/build.gradle.kts`（主 App 版本号）

- `voice_assistant/app/src/main/java/com/voiceassistant/ui/AppInfo.kt`
- `docs/当前程序情况.md`
- `docs/项目书.md`

若改动到内置项目文档，还需执行：

- `tools/update_docs_and_encrypt.ps1`（同步生成 `.enc` 资源）
