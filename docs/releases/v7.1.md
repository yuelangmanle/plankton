# 浮游动物一体化 v7.1（710）

## 本次更新

- 专注录入改为从页头到物种计数的连续滚动列表，点位、会话状态和统计不再固定在列表外；大数据仍按需渲染。
- 长物种名默认可显示两行，点按或长按名称可查看完整中文名和拉丁名，计数按钮不会被挤压或触发误操作。
- 图片识别的 API1、API2 和图片识别服务改为纵向独立选择，未配置地址或模型的提示完整保留在所属服务下。
- Web 依赖和锁文件更新；Android/语音助手自动依赖更新限制为兼容补丁，避免跨 `compileSdk` / AGP 版本导致构建失败。

## 安装说明

这是正式签名的覆盖升级包。已安装 v6.9 或 v7.0 正式版可直接覆盖；仍在使用旧 Debug 签名包的设备首次切换正式版需先卸载旧包。
