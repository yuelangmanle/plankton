# 浮游动物一体化 v7.0（700）

## 本次更新

- 普通物种页支持卡片空白区 `+1`、长按仅选中和可关闭的快速计数；手动计数新增 `− / +`。
- 增加工作会话栏，明确当前数据集、点位、保存状态、后台任务、撤销和重做。
- 多图计数冲突必须人工确认“相加 / 取最大 / 覆盖来源”，不再自动取最大值；每图显示任务状态，可取消整批或重试失败单图。
- 大图采用采样解码，图片批量写入放到后台；设置可查看实际刷新率和面板支持档位。

## 安装说明

这是正式签名的覆盖升级包。已安装 v6.9 正式版可直接覆盖；仍在使用旧 Debug 签名包的设备首次切换正式版需先卸载旧包。
