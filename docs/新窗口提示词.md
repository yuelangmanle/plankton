## 4) 总体要求（长期约束）

- 手机优先，并适配平板（自动/手机/平板 UI 模式）
- 离线优先；网络仅用于可选 AI 辅助（OpenAI 兼容 Base URL/Model/Key，可双 API）
- Excel 导出必须为 `.xlsx` 多 sheet，且采用“模板驱动填值”保持样式一致
  - 模板：`android/app/src/main/assets/templates/table1.xlsx`、`android/app/src/main/assets/templates/table2.xlsx`
- 数据集管理：新建/复制/删除/重命名；备份导入/导出（JSON）；分享
- 计算：密度/生物量/H/D/J/Y 等指标，公式与边界规则以文档为准
- 导出预览：全屏预览 + 固定表头 + 缩放控件 + 预览摘要（条目数/点位数/统计摘要）
- API 管理：使用 API 中心管理服务连接、动态模型、任务路由与调用记录；API1/API2 仅为旧配置兼容层，Key 必须由 Keystore 保存。模型候选仅可由当前账号在线获取，默认智能推荐，支持长按查看完整名与一键采用能力建议。
- AI 回答：分类、湿重、主助手和全局助手均应把最终答案与思考过程分离；默认显示最终答案，模型返回的 think/reasoning_content/中文思考段可折叠展开。结构化解析和数值候选只能使用最终答案。
- AI 完整性：全文阅读禁止复用字符预览上限；分类、湿重、主助手等文本任务必须保留足够首轮 token，并在服务端明确 length 终止或只返回思考过程时自动续写，优先得到最终结论。
- Apilot：发送本机 API 时必须让用户选择服务并只发送所选 apiProfiles；Key 默认关闭。未安装时引导至 <https://github.com/yuelangmanle/Apilot>，不要影响“从 Apilot 选择”已有链路。
- Apilot 可用性：不得以 resolveActivity 的预检结果阻断 V2 显式 Intent；先尝试真实导入/发送，只有 ActivityNotFound 等实际启动失败才显示未安装引导。
- 发布与更新：主 App 正式签名材料仅存于仓库 `.secrets/release-signing/`（Git 忽略）；GitHub Releases 提供 APK，设置页可检查更新并调用系统下载器。旧 Debug 签名包首次迁移到正式签名包需要卸载一次。
- 流程：Superpowers 与其他工作流按任务风险按需使用，不强制 bootstrap 或固定子流程；用户未要求时不执行真机模拟点击。
- 现场录入与图片：普通物种页快速 `+1` 默认开启但可关闭，长按只选中；多图不同计数必须人工确认策略后才可应用。不得恢复“跨图片自动取最大值”；图片大对象变换不得在主线程执行。
