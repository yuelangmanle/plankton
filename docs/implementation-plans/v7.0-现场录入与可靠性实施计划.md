# v7.0 现场录入与可靠性实施计划

**目标：** 把高频现场录入、图片识别确认和数据保存状态变成可追溯、可撤销且不依赖猜测的主链路。

**版本目标：** 主 App `7.0 (700)`；语音助手没有功能改动，不调整版本、不打包。

## 约束

- Android 最低版本、数据集 JSON 兼容层和正式签名保持不变。
- AI 与本地规则只能生成待确认动作，不能静默覆盖已有现场数据。
- 同一物种、同一点位的跨图片计数冲突必须人工选择处理方式。
- 不做 ADB 模拟点击；通过单元测试、构建、静态检查和人工真机验收完成验证。
- API Key、签名私钥、`api_backups/` 均不得提交。

## 任务清单

- [x] 新增纯领域的工作会话与快速计数规则，并先写失败测试：会话摘要、保存状态、连续 `+1` 撤销合并、非负计数。
- [x] 将 `MainViewModel` 的编辑链路接入会话状态：保存中/已保存、最后保存时间、撤销/重做数量、统一快速计数入口与离页强制保存。
- [x] 在物种页、专注录入页加入轻量工作会话栏；普通页卡片空白区 `+1`，长按仅选中，子控件不触发；手动计数弹窗增加 `− / +`。
- [x] 新增跨图片识别冲突领域模型和失败测试；删除“自动取最大值”，改为待决冲突、相加/取最大/覆盖三种明确选择，未解决时禁用应用。
- [x] 将图片识别进度提升为按图可见的队列状态，保留取消、失败和单图重试；图片解码继续在 IO 调度并按目标尺寸采样。
- [x] 为备份导入补充导入前影响范围、同名数据集冲突数量和导入完成摘要；破坏性导入前创建快照。
- [x] 为大数据建立可重复的纯领域基准生成器与测量入口，覆盖 100 点位 × 500 物种的快速计数；高刷状态显示实际显示模式。
- [ ] 升级主 App 到 `7.0 (700)`，同步更新日志、项目书、加密文档、发布清单与 GitHub Release；重新构建、运行单元测试、核验 APK 版本与签名并推送。

## 验收重点

1. 普通物种页连续点卡片空白区可增加当前点位计数；长按只选中；计数/编辑/菜单按钮不会误加。
2. 手动计数最小为 `0`，确认一次写入；连续快速计数可一次撤销。
3. 多张图片同一“点位 + 物种”出现不同计数时，应用按钮要求先选定每个冲突的策略。
4. 顶部始终可读出当前数据集、当前点位、保存状态与撤销/重做状态。
5. 既有数据集、备份导入、导出和 API 中心回归通过；语音助手产物不变。
